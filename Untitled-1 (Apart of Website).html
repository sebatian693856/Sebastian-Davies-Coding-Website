Coding

Coding is writing instructions for a computer. It tells the computer what to do. It uses special languages, similar to learning to speak Spanish or French, but instead, you are communicating with a computer. People use coding to create games, apps, websites, and even to control robots. There are many rules, which can make it confusing at first. However, with practice, it becomes easier and even enjoyable. Coding is important because much of what we use every day is built with code.

Why is coding important?

Coding is a valuable skill because it allows you to create, solve problems, and understand the technology that shapes modern life. By learning to code, you gain the ability to build websites, apps, and tools that can make everyday tasks easier or more efficient. It also strengthens logical thinking and creativity, since coding requires you to break complex problems into smaller, manageable steps and design clear solutions. In many careers, from business to science to the arts, coding is becoming increasingly useful, giving those who understand it a strong advantage in the job market. Additionally, coding encourages persistence and adaptability, as mistakes are a natural part of the process and learning to fix them builds resilience. Beyond career benefits, coding can be personally rewarding, allowing you to turn your ideas into real, functional projects that others can use and enjoy in meaningful ways.

What is Procedural programming languages

All the types of Procedural programming languages that this webpage will explain are C++, C, Java and Pascal. This page will explain them all. C++ is a cross platform language that can be used to crate high-peformence applications. C++ coding was created by the smart person called Bjarne Stroustrup the main idea of it was to be an extension to the C coding language. C++ is one of the top used programming platforms ever. It is a object-orientated programming language which gives a clear structure. Java is also an object-orientated programming language similar to C++. Java was invented by Sun Microsystems in 1995. Java can run on any program that has an operating system with a JVM. Java ensures reliability and security when it comes to keeping your code safe. Pascal is one of the four procedural proggraming languages this page will explain. Pascal was designed in 1968 and published by Niklaus Wirth in 1970. Pascal is named after the French Mathematician Blaise Pascal. The Pascal program runs on many platforms including Windows, Mac OS, and various versions of UNIX/Linux. C is one of the many procedual programming languages. C was created by Dennis Ritchie at Bell Labs in 1972. C is a powerful and flexible language that is widely used in system programming and embedded systems. C is used to create programs that need to run fast and work closely with the computer. The diffrence between C++ and C is that C++ was created as an extension for C.

<script>
(function() {
    const canvas = document.getElementById("gameCanvas");
    const ctx = canvas.getContext("2d");
    const scoreDisplay = document.getElementById("score");

    const gridSize = 20; // size of each cell
    let snake = [{ x: 10, y: 10 }];
    let direction = { x: 1, y: 0 };
    let food = randomFood();
    let score = 0;
    let speed = 150; // ms per frame

    // Listen for arrow keys
    document.addEventListener("keydown", e => {
        if (e.key === "ArrowUp" && direction.y === 0) direction = { x: 0, y: -1 };
        else if (e.key === "ArrowDown" && direction.y === 0) direction = { x: 0, y: 1 };
        else if (e.key === "ArrowLeft" && direction.x === 0) direction = { x: -1, y: 0 };
        else if (e.key === "ArrowRight" && direction.x === 0) direction = { x: 1, y: 0 };
    });

    function randomFood() {
        return {
            x: Math.floor(Math.random() * (canvas.width / gridSize)),
            y: Math.floor(Math.random() * (canvas.height / gridSize))
        };
    }

    function gameLoop() {
        update();
        draw();
        setTimeout(gameLoop, speed);
    }

    function update() {
        // Move snake
        const head = { x: snake[0].x + direction.x, y: snake[0].y + direction.y };

        // Wrap around edges (Snake.io style)
        if (head.x < 0) head.x = canvas.width / gridSize - 1;
        if (head.x >= canvas.width / gridSize) head.x = 0;
        if (head.y < 0) head.y = canvas.height / gridSize - 1;
        if (head.y >= canvas.height / gridSize) head.y = 0;

        // Check collision with self
        for (let segment of snake) {
            if (segment.x === head.x && segment.y === head.y) {
                resetGame();
                return;
            }
        }

        snake.unshift(head);

        // Check if food eaten
        if (head.x === food.x && head.y === food.y) {
            score++;
            scoreDisplay.textContent = "Score: " + score;
            food = randomFood();
            // Increase speed slightly
            if (speed > 50) speed -= 5;
        } else {
            snake.pop();
        }
    }

    function draw() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);

        // Draw snake
        ctx.fillStyle = "lime";
        for (let segment of snake) {
            ctx.fillRect(segment.x * gridSize, segment.y * gridSize, gridSize - 2, gridSize - 2);
        }

        // Draw food
        ctx.fillStyle = "red";
        ctx.fillRect(food.x * gridSize, food.y * gridSize, gridSize - 2, gridSize - 2);
    }

    function resetGame() {
        snake = [{ x: 10, y: 10 }];
        direction = { x: 1, y: 0 };
        score = 0;
        speed = 150;
        scoreDisplay.textContent = "Score: 0";
        food = randomFood();
    }

    gameLoop();
})();
</script>
