Things Made with C++

This page will show a simple thing made with the C++ coding program. Famous things made with C++ are 1. Desktop Applications Adobe Photoshop / Illustrator – Image editing and design tools. Microsoft Office (parts) – Some performance-critical components. Winamp – Classic media player. 2. Games & Game Engines Unreal Engine – AAA game engine used for Fortnite, PUBG, etc. Counter-Strike – Originally built on the C++-based Source engine. World of Warcraft – Large-scale MMORPG with C++ backend. 3. Operating Systems & System Software Windows OS (core parts) – Many kernel and driver components. macOS (parts) – Uses C++ in performance-critical subsystems. Linux desktop environments – KDE Plasma is written in C++ (Qt framework). 4. Browsers Google Chrome – Core rendering engine (Blink) is in C++. Mozilla Firefox – Gecko engine is written in C++. 5. Embedded Systems Car infotainment systems – Many use C++ for speed and hardware control. Medical devices – MRI scanners, patient monitori systems.
